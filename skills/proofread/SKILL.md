# Skill: improve-text

- Analyze the provided text.
- Correct grammar, spelling, and phrasing while maintaining the original register.
- For every paragraph or logical block, place the optimized version directly below the original text.
- Ensure a clear separation between the original and the optimized version (e.g., use blockquotes or clear labeling).
- When dealing with code-related content, ensure idiomatic correctness and clarity.
- Fact-check claims, especially technical claims.
- Suggest missing content if necessary.
- If unsure, write down a note.

Invocation: /improve-text [file]
